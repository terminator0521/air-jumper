## How it is Made



Air Jumper is created using Godot engine and its scripting language GDScript, with textures drawn using Aseprite



## About the Game



This is a 2D platform shooter with its core mechanics inspired by Konami's Contra Series. The goal is to be able to shoot down as many missles in the air while also using them to continue traversing forward. You can only one active bullet. And falling off or going off screen will be immediate death.



## How to run game



1. Download air_jumper_win64.zip from the latest release in GitHub releases.
2. Extract the folder contents to a place you can find it.
3. Open the extracted folder and run air_jumper.exe



## AI Disclosure



AI was only used for me to learn how GDScript worked through example code. No Ai was used to generate pieces of code that directly changes how the game works.



## Final Mentions



CONTROLS:

Side arrows: move left or right

Up: aim up

Z: jump

X: Shoot

Down + Z: drop down from missle

*Certain 2 arrow key combinations can let you aim diagonally while moving*
